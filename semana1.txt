-¿Por qué distribuir?
latencia, tolerancia a fallos, escalabilidad y autonomía cosas que no pueden faltar en una BD Distribuidos.

-3 cosas importantes para tener una BDD?
tranparencia, Integridad de los datos y Seguridad



-que es una BD Distribuida?
de forma transparente
es un conjunto de bases de datos interconectadas en diferentes lugares, que se muestran al usuario como un único sistema de base de datos.
